# Bit.krshr

A small bitcrusher effect plugin (C++, [JUCE](https://juce.com)), based on my DIY Bit.krshr guitar effect pedal.

I built the pedal first (Arduino Nano-compatible board, C++) and then ported the idea to a plugin. It was my first project with JUCE. I'm a beginner in audio programming, so the code is simple on purpose, and I'm happy about feedback.

![Screenshot of the Bit.krshr plugin in Ableton Live](docs/screenshot1.png)

> **Warning:** bit crushing can get loud. Turn your volume down before you start.

## What it does

Bit.krshr reduces the sound quality on purpose, in two ways:

- **Bit reduction:** fewer bits per sample, so the signal gets rougher.
- **Sample-and-hold:** the signal is sampled less often, which adds aliasing and a lo-fi sound.

## Install (macOS, VST3)

1. Download the latest release from the Releases tab of this repository (or from my [portfolio page](https://erenkoc90.github.io/portfolio/)). The current build is for **Apple Silicon (arm64)** Macs only.
2. Unzip it and copy `Bitkrshr.vst3` to `/Library/Audio/Plug-Ins/VST3/` (all users) or `~/Library/Audio/Plug-Ins/VST3/` (only you).
3. Open your DAW and rescan your plugins.

The plugin is **not code-signed**, so macOS may block it the first time. You can allow it in *System Settings > Privacy & Security*. Advanced users can also remove the quarantine flag:

```
xattr -dr com.apple.quarantine ~/Library/Audio/Plug-Ins/VST3/Bitkrshr.vst3
```

(Use `/Library/Audio/Plug-Ins/VST3/Bitkrshr.vst3` if you installed it for all users.) Only install the plugin if you downloaded it from this repository or from my portfolio page.

## Build from source

You need:

- macOS with Xcode
- the [JUCE](https://juce.com) framework (not included in this repository; check its licence)

Steps:

1. Download JUCE from juce.com and build or open the **Projucer**.
2. Open `Bitkrshr.jucer` in the Projucer.
3. In the Projucer, set the **module paths** (and the JUCE modules path under *File > Global Paths*) to your own JUCE folder. The paths in the project file are from my computer.
4. Choose the *Xcode (macOS)* exporter and click *Save and Open in IDE*.
5. In Xcode, select the **Bit.krshr - VST3** scheme, set the configuration to **Release** (*Product > Scheme > Edit Scheme > Run > Build Configuration*), and build (Cmd+B).
6. The built plugin is in `Builds/MacOSX/build/Release/`. By default Xcode also copies it to `~/Library/Audio/Plug-Ins/VST3/`.

If the build fails with a sandbox or "Operation not permitted" error during code signing, set *User Script Sandboxing* to **No** in the Xcode build settings and do a clean build.

The `Builds/` folder is generated by the Projucer and is not part of this repository.
